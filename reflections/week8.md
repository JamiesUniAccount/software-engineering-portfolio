# Task 1
For this task, the external attribute I will be using is usability. The app I have chosen to take a look at is Instagram, as it is an app I use daily.
Usability refers to how easy an application is to learn for the user. The SUS score measures how easy users will find an app to use.
To get this SUS score I would:

- Ask a few Instagram users to complete a SUS quiz.
- The quiz will contain around 10 questions about their experience using the app.
- Based on the users answers, we would calculate a SUS score from 1 to 100.
- I would collect the answers from the users after 5 days, allowing them to use Instagram an ample amount before submitting their answers.


For the second measurement, I will be using time-on-task, which tracks the users time to complete tasks within the app. This will help determine how efficiently users can move through the app.
To collect this data I would:

- Ask around 10 users to complete 3 common tasks on instagram.
- I would time each of these users to see how long it takes them to complete each task.
- Calculate the average time to complete each task. If a completion time is short, that suggests the app is easy to navigate.
- This would take place over a few days.
